# krati.fm — Krati, on repeat

My personal portfolio, designed like a playlist. The tracklist at the top is
the table of contents: About me, Projects, Research, Art, Skills, Experience
and Contact. Each project card opens its own page with more detail.

**Live site:** https://maheshwarikrati4-collab.github.io

## What's inside

- `index.html`: the main page
- `projects/`: one page per project (Vybe Learn, Canteen Crowd-Flow,
  Global Superstore Analysis, Campus Platforms hackathon)
- `style.css`: layout, the blue palette and phone styles (shared by every page)
- `script.js`: the "now playing" bar that follows your scroll, shuffle, the art
  lightbox, and a play button that plucks a short *sargam* (sa re ga ma pa…)
  using the Web Audio API
- `assets/`: my photo, sticker images, `art/` with my drawings, `ngo/` with volunteering photos (shared with the NGO's permission)

Plain HTML/CSS/JS, no frameworks and no build step. Hosted on GitHub Pages.
