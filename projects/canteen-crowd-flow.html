Canteen Crowd-Flow

A simulation of the 1 PM canteen rush.

Role
Co-builder
Type
Course team project
Method
Agent-based simulation

What it is

Anyone who has queued in a college canteen at lunchtime knows the chaos. We modelled it: every student is an agent who arrives, picks a counter, waits, gets served and leaves.

Arrivals, service times and routing are all randomised, so each run plays out a little differently, just like a real lunch break.

What I did

  • Co-built the stochastic, agent-based model.
  • Ran it across four scenarios: queue wait times, counter hotspots, exit load, and entry–exit flow.

Built with

  • Python
  • Simulation
  • Probability
