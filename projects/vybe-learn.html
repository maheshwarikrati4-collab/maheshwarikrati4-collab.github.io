Vybe Learn

An AI tutor that teaches data science on your own data.

Role
Co-developer
When
Sep 2026 – present
Type
AI product
Status
MVP live, still in development

What it is

Most data science courses hand you the same tidy practice dataset. Vybe Learn flips that: you bring your own data, and the tutor builds the lesson around it.

Behind the scenes, Gemini-powered agents work together to explain concepts, set tasks and adapt the curriculum to how you're doing.

What I did

  • Co-developing the product, from the agent setup to the learning flow.
  • Shipped the MVP and deployed it on Vercel.

Built with

  • Gemini API
  • Multi-agent systems
  • Prompt writing
  • Vercel
